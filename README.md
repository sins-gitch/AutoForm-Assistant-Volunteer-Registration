# 通用问卷自动填报助手

（各位请不要做宣传，被拿下就糟糕了）

上边的文件是基于电脑端的程序，release中的文件是基于安卓端的程序

一个用于自动填写问卷的辅助工具，支持多种常见表单字段的自动识别与填充，帮助您提高问卷填报效率。

## 🌟 核心功能

*   **通用网址支持**：在顶部输入任意 HTTP/HTTPS 问卷网址，点击“开始自动填写”即可运行。
*   **多标签连续作业**：支持连续打开不同网址，无需先提交前一张问卷，所有任务均在新标签页中独立进行。
*   **丰富的字段解析与自动填写**：
    *   **文本输入**：自动填写姓名、学号、学院等常见文本字段。
    *   **选项类字段**：自动识别并填写单选题、下拉选项。
    *   **定制化下拉框**：针对“性别”（男/女）、“政治面貌”、“楼栋长/楼层长”（是/否）等字段提供精准匹配支持。
    *   **特定逻辑处理**：
        *   **活动时间**：末尾相关单选题若已选中则保留；若未选中，则自动按第一个可用选项操作。
        *   **进群图片**：在提交前自动保存问卷最后一道题相关的进群图片（自动排除扫码分享好友的图片）。
*   **智能诊断与日志**：
    *   运行日志实时显示关键字段的填写状态（如：性别=已设置/未设置、政治面貌=已设置/未设置），未选中时会自动提醒。
    *   自动生成 `<问卷标识>_性别政治面貌诊断.json`，记录题目识别、选项匹配和操作结果，方便排查识别问题。
*   **安全提交机制**：默认关闭自动提交功能。所有内容填写完成后，您可以人工核对，确认无误后再使用“核对并提交所选问卷”按钮手动提交。

## 🚀 如何使用

1.  **启动软件**：解压软件包后，运行 `启动助手.bat`。
2.  **环境配置**：如果您以前安装过 Playwright，一般无需重复运行“首次安装.bat”。（如首次使用，请先运行该文件安装必要环境）。
3.  **保留个人资料**：将旧程序文件夹里的 `config.json` 复制到新文件夹即可保留您的个人资料（如为首次使用，请按软件提示配置个人信息）。
4.  **确认配置**：在软件窗口中确认“性别”和“政治面貌”等下拉选项已选择正确答案，并点击保存。
5.  **开始填报**：输入问卷网址开始运行，等待填写完成。您可以在运行日志中查看各项内容是否已成功核实选中。

## ⚠️ 重要提示与免责声明

*   **隐私安全**：`config.json` 文件包含了您的个人信息（如姓名、政治面貌等），请**仅存于本机**，切勿公开分享或上传至云端。
*   **网站限制**：本助手无法跳过登录、验证码、表单满员等网站自身的限制。
*   **活动状态**：如果问卷中的“活动时间”显示“已满”，可能无法正常报名，这与软件自动勾选功能无关。
*   **真实原则**：请确保填报内容与您的真实情况相符。请勿使用本工具自动声明已经进群或参加了活动，除非这与您的真实情况一致。
*   **兼容性说明**：不同问卷平台（如金数据等）的表单模板可能存在差异。如果在使用中发现特定字段未能正确勾选，可查看软件生成的诊断 JSON 文件进行排查。
